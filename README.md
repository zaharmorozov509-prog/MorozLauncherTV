# 🎮 MorozLauncherTV

**MorozLauncherTV** — это кастомный лаунчер для Android TV и ТВ-приставок, выполненный в стиле интерфейса PlayStation 5. Он заменяет скучный стандартный рабочий стол на стильную карусель приложений с плавными анимациями, темной темой и кучей полезных фишек.

![Платформа](https://img.shields.io/badge/platform-Android%20TV-green)
![Статус](https://img.shields.io/badge/status-active-brightgreen)

## ✨ Основные возможности

*   🕹 **Дизайн в стиле PS5:** Горизонтальная карусель, крупные иконки, темный фон и неоновое свечение.
*   ⚡ **Оптимизация против лагов:** Лаунчер работает максимально быстро, без задержек при переключении пультом.
*   🔄 **Автообновление:** Лаунчер сам проверяет новые версии на GitHub и предлагает обновиться в один клик.
*   🌤 **Виджет погоды:** Показывает текущую температуру и погоду за окном.
*   🔋 **Индикатор пульта:** Показывает уровень заряда Bluetooth-пульта (если поддерживается телевизором).
*   🌙 **Режимы работы:** Обычный, «Кино» (теплые цвета), «Игры» (яркие) и «Ночь» (приглушенные).
*   🎨 **Персонализация:** Смена цветовых тем (синяя, красная, зеленая, фиолетовая).
*   🖼 **Свои фото:** Установка собственных обоев и аватарки профиля прямо с флешки.
*   ⚙️ **Встроенные настройки:** Все функции собраны в удобном меню (иконка ⚙️ в начале карусели).
*   🚀 **Умный старт:** Заставка *"By Moroz"*, автоматическая загрузка приложений и приветствие пользователя.

## 📱 Поддерживаемые устройства

Лаунчер устанавливается на любые устройства с операционной системой **Android TV** или **Google TV**.

**✅ Точно работает на:**
*   Sony Bravia
*   TCL
*   Xiaomi Mi TV / Redmi TV
*   Philips
*   Panasonic
*   Sharp
*   CHiQ
*   **Яндекс ТВ (Станции)** и устройства на YaOS (через установку APK с флешки)
*   Любые внешние ТВ-приставки (Mi Box, Chromecast с Google TV и т.д.)

**❌ Не работает на:**
*   Samsung (система Tizen)
*   LG (система webOS)
*(Для них нужна внешняя Android-приставка).*

## 📥 Установка

1.  Перейди в раздел **[Releases](https://github.com/zaharmorozov509-prog/MorozLauncherTV/releases)**.
2.  Скачай последний файл **`app-debug.apk`**.
3.  Перекинь файл на телевизор (через USB-флешку, приложение Send Files to TV или облако).
4.  Открой файл на телевизоре и установи (разреши установку из неизвестных источников, если потребуется).
5.  Нажми кнопку **«Домой»** на пульте и выбери **MorozLauncherTV** в качестве лаунчера по умолчанию.

## 🛠 Управление

*   `◀ ▶` (Стрелки влево/вправо) — переключение между приложениями.
*   `OK` (Enter) — запуск приложения или вход в настройки.
*   `Кнопка «Меню»` (или долгое нажатие OK) — вызов быстрого меню.

## 🧑‍💻 Для разработчиков

Проект собирается автоматически через **GitHub Actions**. Исходный код написан на **Kotlin** (для доступа к системе) и **HTML/CSS/JS** (для интерфейса).

**Структура:**
*   `app/src/main/java/.../MainActivity.kt` — нативный код (запуск приложений, чтение списка программ).
*   `app/src/main/assets/index.html` — весь интерфейс и логика лаунчера.
